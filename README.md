# 🎯 Hangman Game — Classic Word Guessing Fun!

> **"Guess the word, or the man hangs!"**

Welcome to the **Hangman Game**, a fun and interactive web-based game built using **HTML**, **CSS**, and **JavaScript**. It's a digital spin on the classic classroom game that tests your vocabulary and guessing skills!

## 🚀 Features

✨ **Random Word Generator** – Get a new challenge every time  
👨‍🎨 **Dynamic Hangman Drawing** – Visual feedback as you guess wrong letters  
🎯 **Intuitive UI** – Clean, simple, and user-friendly design  
💻 **Fully Responsive** – Works well on desktop and mobile  
🔁 **Replay Feature** – Play again without refreshing the page  

---

## 🧠 How to Play

1. A random word is chosen, but hidden.
2. Guess one letter at a time.
3. Each wrong guess draws a part of the hangman.
4. Guess the full word before the man is fully hanged!
